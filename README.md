# Interview Voice Lab

한국어 취업 면접 답변의 전달 습관을 브라우저에서 점검하는 정적 웹 애플리케이션입니다. 사용자가 질문에 마이크로 답하면 답변 시간, 응답 시작 시간, 실제 음성 감지 시간, 침묵, 음량, 발화량과 필러 표현을 가능한 범위에서 측정합니다.

외부 LLM API, API 키, 별도 서버가 필요하지 않습니다. 녹음 데이터는 저장하거나 서버로 전송하지 않으며, 최근 결과는 사용 중인 브라우저의 `localStorage`에만 보관합니다.

## 주요 기능

- 종합·직무·인성 면접 유형과 5·10문항 선택
- 세션 내 중복 없는 한국어 면접 질문 무작위 출제
- `MediaRecorder`를 이용한 답변 구간 녹음 처리(녹음 데이터는 즉시 폐기)
- Web Audio API의 `AnalyserNode`를 이용한 실시간 음량 및 침묵 감지
- 응답 시작 시간, 전체 답변 시간, 실제 발화 시간, 침묵 시간·횟수, 평균 음량·음량 변화 측정
- 지원 환경에서 Web Speech API 기반 `ko-KR` 음성 텍스트 변환
- 인식 텍스트의 글자 수, 분당 발화량, 필러 표현 횟수 계산
- 전체 요약과 질문별 상세 결과, 규칙 기반 연습 메시지 제공
- 최근 10개 면접 결과를 `localStorage`에 저장하고 시작 화면에서 요약 확인
- 마이크 권한 거부, Web Audio·MediaRecorder·SpeechRecognition 미지원 시에도 가능한 기능으로 계속 진행
- 데스크톱·태블릿·모바일 반응형 UI와 키보드 포커스 스타일

## 실행 방법

ES 모듈을 사용하므로 파일을 직접 더블클릭하기보다 로컬 정적 서버로 실행하는 것을 권장합니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. 마이크는 보안 컨텍스트에서만 사용할 수 있으므로 배포 환경에서는 HTTPS가 필요합니다. `localhost`는 대부분의 브라우저에서 안전한 개발 환경으로 취급됩니다.

## GitHub Pages 배포

1. 이 폴더의 파일을 GitHub 저장소 기본 브랜치에 올립니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Build and deployment**에서 **Deploy from a branch**를 선택합니다.
4. 배포 브랜치와 `/ (root)` 폴더를 선택한 뒤 저장합니다.
5. GitHub가 제공하는 `https://<계정>.github.io/<저장소>/` 주소로 접속합니다.

모든 자산은 상대 경로를 사용하며 `.nojekyll`을 포함하므로 별도 빌드나 경로 수정 없이 GitHub Pages에서 실행할 수 있습니다.

## 브라우저 호환성

- **데스크톱 Chrome 우선 지원:** Web Audio, MediaRecorder, Chrome의 `webkitSpeechRecognition`을 사용할 수 있습니다.
- **Edge 및 기타 Chromium 브라우저:** 대부분의 마이크 분석 기능이 동작하지만 음성 인식 제공 여부는 환경에 따라 다릅니다.
- **Safari / iPad / iPhone:** Web Audio와 MediaRecorder 지원 범위가 OS 버전에 따라 다르며, 음성 인식이 제공되지 않거나 동작 방식이 다를 수 있습니다.
- **Firefox:** 오디오 측정과 녹음은 가능할 수 있지만 Web Speech API 음성 인식은 일반적으로 제공되지 않습니다.

지원되지 않는 API는 자동으로 건너뜁니다. 음성 인식이 없더라도 질문 진행, 응답 시간 측정, 가능한 경우의 오디오 분석, 결과 저장은 중단되지 않습니다. 실제 지원 범위는 브라우저 버전, 운영체제, 보안 설정과 네트워크 정책에 따라 달라질 수 있습니다.

## 측정 지표의 한계

이 앱의 결과는 전문 음성 분석이나 객관적인 면접 평가가 아닌 **브라우저 마이크 기반 참고 지표**입니다.

- 주변 소음, 마이크 거리와 품질, 브라우저의 자동 음량 보정이 음량·침묵 감지에 영향을 줍니다.
- 음량 임계값과 최소 침묵 지속시간은 `js/audioAnalyzer.js`의 `VOLUME_THRESHOLD`, `MIN_SILENCE_DURATION_MS` 상수로 관리합니다.
- 실제 발화 시간은 음량이 임계값 이상인 구간을 합산한 값이며 음성학적으로 정밀한 발화 시간과 다를 수 있습니다.
- 발화량과 필러 횟수는 음성 인식 결과가 있을 때만 계산됩니다. 인식 오류, 띄어쓰기와 네트워크 상태에 따라 값이 달라질 수 있습니다.
- Web Speech API의 음성 텍스트 변환은 브라우저 환경에 따라 네트워크 서비스를 사용할 수 있습니다.
- 규칙 기반 메시지는 연습 방향을 돕기 위한 것으로 면접 점수나 합격 가능성을 뜻하지 않습니다.

기본 필러 목록은 `js/app.js`의 `FILLER_WORDS` 상수에서 쉽게 변경할 수 있습니다.

## 향후 LLM API 확장 지점

현재 버전에는 외부 LLM 호출이 없습니다. 나중에 답변 내용 피드백을 추가할 경우 `js/app.js`에서 답변이 확정되는 `stopAnswer()` 이후의 `transcript`를 별도 분석 모듈에 전달할 수 있습니다. 전체 면접 피드백은 `finishSession()`에서 만들어지는 질문·답변 배열을 입력으로 연결할 수 있습니다.

확장 시에는 API 키를 브라우저 코드에 포함하지 말고 별도의 서버리스 함수나 백엔드 프록시에서 안전하게 보관해야 합니다. 네트워크 분석에 동의하지 않는 사용자도 현재의 로컬 음성 지표를 계속 사용할 수 있도록 LLM 피드백을 선택 기능으로 분리하는 구성이 적절합니다.
